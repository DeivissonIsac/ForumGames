Forum Games é um projeto pequeno e simplificado feito em flask. O mesmo teve seu deploy feito no RailWay https://forumgames.up.railway.app/

O objetivo é aplicar o conhecimento e fazer um sistema basico em flask tanto no back-end quanto no front-end

Tecnologias Utilizadas:
Flask, Boostrap, html, SQLite

Com esse projeto foi possível aprender: flask e suas ferramentas, formularios no flask, conexão com banco de dados, criptografia, autenticação de usuários.
Além disso aprimorei algumas habilidades que já possuía antes.
